# Canonical Ledger Schema

A strategy-agnostic schema for reproducible trade ledgers.

The project standardizes causal timestamps, lifecycle state, prices, costs, outcomes, and evidence without exposing alpha logic or proprietary datasets.

Planned v0.1 fields include trade identity, instrument, side, status, signal/entry/exit timestamps, entry/exit prices, costs, gross/net outcomes, exit reason, and causal evidence.

This repository contains only generic schemas, validators, and synthetic examples.
